# cup3D

🫗 [English](README.md) | [日本語](README_ja.md) 🫗

- ラリーにタイムアタック以外の評価指標(水の入った紙コップ)を持ち込みます。
- あなたは水の入った紙コップをカップホルダーにセットしてから豆腐配達に出かけます。
- assetto corsaシリーズ共通(?)のテレメトリデータ(ロールとピッチ)を読み出し、紙コップの中の水の揺れ具合をシミュレートします
- ロアフレンドリーで説得力のある立体的な紙コップ表示
- 以下を簡単な操作で変更可能
   - 紙コップの位置を移動（マウスドラッグ）
   - 拡大・縮小(マウスホイール回転)
   - カメラ向き(マウスミドルボタン＋ドラッグ)
   - 水の量(右クリックメニュー)
   - その他いろいろ(右クリックメニュー & 設定ファイル)

- 水がこぼれると「So bad !」と表示する(文字列は変更可能)
- こぼれた回数を絵文字(🫗)で表現
- 水面の見え方も設定可能(格子/グラデーション/警告色)
- その他の細かい揺れ具合の強弱なども設定ファイルで調整可能
- ゲームを起動しなくても、キー操作で水の揺れ具合を確認可能(設定ファイルでdebug=true)

楽しんで !!
