This is a machine translation of the original Japanese text. Sorry if it's hard to read.

- Introduces a performance metric beyond just time-attack (a paper cup filled with water) to the rally experience.
- You place a water-filled paper cup into the cup holder before setting off on your tofu delivery run.
- Reads telemetry data (roll and pitch)—common across the *Assetto Corsa* series—to simulate the sloshing of water inside the cup.
- Features a realistic, 3D paper cup display that fits the game's atmosphere.
- Easily adjustable settings:
   - Cup position (mouse drag)
   - Scale (mouse wheel scroll)
   - Camera angle (middle mouse button + drag)
   - Water volume (right-click menu)
   - Various other options (right-click menu & config file)
- Displays "So bad!" when water spills (text is customizable).
- Tracks the number of spills using an emoji (🫗).
- Customizable water surface appearance (grid/gradient/warning color).
- Fine-tune sloshing intensity and other details via the config file.
- Check the water movement using keyboard controls without launching the game (set `debug=true` in the config file).
